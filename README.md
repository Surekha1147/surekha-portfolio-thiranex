# 🌐 Personal Portfolio Website

This project is a **multi‑page personal portfolio website** built as part of the **Thiranex Virtual Internship (Ref: THX-MAY1426-898)**.  
It showcases my resume, skills, projects, certifications, and achievements in a modern, accessible, and SEO‑optimized format.

---

## 🚀 Features
- **Semantic HTML5 structure** (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **WCAG accessibility compliance** with ARIA labels and roles
- **SEO‑friendly meta tags** (title, description, keywords, OpenGraph)
- **Responsive design** with modern UI/UX principles
- **Accessible contact form** with tab navigation and screen reader support
- **Keyboard‑friendly navigation** and skip‑to‑content link
- **Alt text for all images** to ensure inclusivity

---

## 📄 Sections
- **Home** – Introduction and tagline  
- **About** – Objective and personal background  
- **Education** – Academic journey with CGPA and percentages  
- **Skills** – Programming languages, frameworks, and coursework  
- **Projects** – Full‑stack and web development projects  
- **Internships & Workshops** – AWS, UiPath, Deloitte, Forage, Hackathons  
- **Certifications** – NPTEL, UiPath, Microsoft, Salesforce, Cisco, TCS iON  
- **Coding Profiles** – LeetCode & HackerRank achievements  
- **Achievements & Activities** – Competitive programming, NSS, hackathons  
- **Contact** – Accessible form with links to LinkedIn, GitHub, and email
